# Architecture decision records

Most decisions fit in a few lines in [DECISIONS.md](../DECISIONS.md). When one needs more room, for example a comparison of options with measurements, write a full record here and link it from the log entry.

- Copy [0000-template.md](0000-template.md) to `NNNN-short-title.md`, using the next free number.
- Use the same decision ID as the log (for example D-023), so the two stay connected.
- Records are never deleted. A replaced decision gets the status "Superseded by D-0NN".
